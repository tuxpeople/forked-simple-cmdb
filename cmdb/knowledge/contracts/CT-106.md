behaviour, which is the explicit INSERT OR IGNORE plus rowcount check.

## Scenario: importing the same file twice inserts nothing the second time

Given a CSV file with header "hostname,ip_address" and one row "imp01,10.0.0.1"
When a client POSTs the file as form field "file" to /api/import/servers
Then the response is HTTP 200 with {"success": true, "imported": 1, "errors": []}
When the client POSTs the same file to /api/import/servers again
Then the response is HTTP 200 with {"success": true, "imported": 0, "errors": []}
And exactly one server "imp01" exists

## Scenario: a missing file is rejected

When a client POSTs to /api/import/servers with no file part
Then the response is HTTP 400
And the body is {"error": "No file provided"}
