Evidence: app.py:442-443, 613. Defaults are asserted through their
observable surfaces (stats grouping and CSV export), since there is no
single-record GET endpoint. Confidence: high.

## Scenario: a server added without environment counts as production

Given an empty CMDB
When a client POSTs {"hostname": "web01"} to /api/server/add
And requests GET /api/stats
Then stats.servers.by_env["production"] is 1
And stats.servers.active is 1

## Scenario: a service added minimally gets protocol tcp and status running

Given a server with id S
When a client POSTs {"server_id": S, "service_name": "nginx"} to /api/service/add
Then the response is HTTP 200 with {"success": true, "service_id": <integer>}
And the services row exported from GET /api/export/services shows protocol "tcp" and status "running"
