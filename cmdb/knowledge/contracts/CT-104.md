Evidence: app.py:482-483, 587-588. Confidence: high; the rowcount check is
identical across all six mutation handlers.

## Scenario: updating a nonexistent server

Given no server with id 9999
When a client PUTs {"hostname": "ghost"} to /api/server/9999
Then the response is HTTP 404
And the body is {"success": false, "error": "Server not found"}

## Scenario: deleting a nonexistent application

Given no application with id 9999
When a client DELETEs /api/application/9999
Then the response is HTTP 404
And the body is {"success": false, "error": "Application not found"}
