## Scenario: adding a new server succeeds

Given no server with hostname "web01"
When a client POSTs {"hostname": "web01"} to /api/server/add
Then the response is HTTP 200
And the body is {"success": true, "server_id": <integer>}

## Scenario: a duplicate hostname is rejected

Given a server with hostname "web01"
When a client POSTs {"hostname": "web01"} to /api/server/add
Then the response is HTTP 400
And the body is {"success": false, "error": "Server already exists"}
