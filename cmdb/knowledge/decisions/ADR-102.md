id: ADR-102
type: decision
title: Hard delete rather than soft delete
status: active
since: 2026-07-31
affects: [cmdb]
implemented_by: [cmdb]
---

All three DELETE endpoints physically remove rows (BR-108). No archived or
deleted status is ever written, although `status` columns exist and could
have carried one, and the UI wraps deletes in a confirm dialog, which
shows destruction was understood at the front end.

Recorded as a decision because the alternative was visibly available and
not taken; but no commit message or comment confirms it was weighed. The
git history ("Add full CRUD functionality") treats delete as plain CRUD.

Confidence: medium. If Tyson says soft delete was ever the plan, this
should be demoted to an assumption and the status vocabulary (ASM-103)
revisited with it.

Confirmed deliberate by the author on 2026-07-31.
