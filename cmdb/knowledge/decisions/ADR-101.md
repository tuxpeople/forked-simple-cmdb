title: SQLite as the only storage, embedded in-process

Storage is a single SQLite file (`cmdb.db`) opened per request. No
database server, no ORM, raw SQL throughout.

This is the product's identity, not a shortcut: the README leads with "No
External Dependencies - Uses SQLite (no database server needed!)" and the
name is *Simple* CMDB. Consequences accepted with it: single-writer
concurrency (the README even documents the "database locked" failure mode
as a troubleshooting step), and per-connection pragmas that are easy to
forget (see ISS-102 for where that bit).

Confidence: high that this is a deliberate decision; it is advertised.
