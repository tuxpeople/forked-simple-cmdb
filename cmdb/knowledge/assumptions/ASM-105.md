The README documents capability that does not exist in the repository:

- `DATABASE_PATH` and `FLASK_ENV` environment variables (app.py reads only
  `PORT` and `DOCKER_CONTAINER`; the DB path is hardcoded `cmdb.db`,
  app.py:24)
- Discovery scripts `discover_linux.py`, `discover_windows.ps1`,
  `discover_network.py`, plus `export_all.py` / `import_data.py` (no such
  files are tracked)
- "Search functionality" and "Bulk operations" in the UI

Assumed: these are aspiration written ahead of implementation, and the
code is authoritative where they disagree.

Confidence: high that the gap exists (verified against `git ls-files` and
app.py); the "aspiration, not lost code" reading is supported by the
roadmap section but is still an inference. Anyone following the README's
`DATABASE_PATH` instruction today silently gets `cmdb.db` in the working
directory instead.
