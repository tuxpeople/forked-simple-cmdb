title: PUT handlers null out omitted fields, losing data silently
status: resolved
since: 2026-07-31
owner: tyson
affects: [cmdb]
---

All three PUT handlers write every editable column from `data.get(...)`, so
any field omitted from the request is overwritten with NULL, and omitting
`hostname` 500s against the NOT NULL constraint (app.py:467-478, 552-563,
635-645). The bundled edit modals mask this by always sending every field, so
any other API caller silently destroys data.

Author confirmed 2026-07-31 that partial update was the intent (BR-109).
Fix: update only keys present in the request body.

Resolved 2026-07-31 in fix/mined-defects: all three PUT handlers build their SET clause from only the keys present in the request body, per BR-109; CT-108 contracts it.
