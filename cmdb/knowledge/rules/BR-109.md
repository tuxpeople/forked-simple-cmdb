---
id: BR-109
type: business-rule
title: Updates are partial; omitted fields keep their values
status: active
since: 2026-07-31
affects: [cmdb]
implemented_by: [cmdb]
verified_by: [CT-108]
supersedes: ASM-101
---

A PUT to a server, application, or service updates only the fields present in
the request body. Omitted fields keep their existing values, and an update can
never null a field the caller did not mention.

Confirmed by the author on 2026-07-31: the current full-replacement behaviour
is a bug masked by edit modals that always send every field, not a design.
See ISS-105 for the defect this supersedes.
