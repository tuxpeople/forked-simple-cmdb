title: Export and import operate only on whitelisted tables
status: active
since: 2026-07-31
affects: [cmdb]
implemented_by: [cmdb]
verified_by: [CT-105]
---

CSV export is allowed for exactly four tables: `servers`, `applications`,
`services`, `dependencies`. CSV import is allowed for exactly two:
`servers` and `applications`. Any other `{table}` value returns HTTP 400
with `{"error": "Invalid table"}` (note: no `success` key; this endpoint
family breaks the usual envelope).

`discovery_history` is deliberately absent from both lists. The whitelist
also serves as the SQL-injection guard for the f-string interpolation of
the table name in the export query (app.py:767), so it is load-bearing for
security, not just UX.

Export succeeds with 200 and an empty file when the table has no rows;
otherwise the first CSV line is the column-name header.

Confidence: high. Whitelists at app.py:760 and app.py:790.
