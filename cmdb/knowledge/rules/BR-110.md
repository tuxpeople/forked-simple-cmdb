status: draft

---

Classification fields accept only their fixed vocabulary, rejected with 400
otherwise, compared case-insensitively and stored in canonical lowercase so
statistics cannot split one value into several:

- criticality: low, medium, high, critical (from the README)
- environment: production, staging, development
- server status: active, inactive, maintenance
- service status: running, stopped, unknown

Author confirmed 2026-07-31 that enums were intended and validation was never
built (ISS-106). Still draft because the exact value lists above are proposed
from the README and sample data; confirm or amend the lists before promoting.
