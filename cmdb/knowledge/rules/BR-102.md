title: Application names are unique
status: draft
since: 2026-07-31

---

An application name identifies at most one application. Adding a duplicate
is rejected with HTTP 400 and
`{"success": false, "error": "Application already exists"}`.

As with BR-101, matching is exact and case-sensitive by SQLite default, not
by visible choice.

Note the error mapping is coarse: any IntegrityError on this insert becomes
"Application already exists", even if some other constraint fired.

Confidence: high. `name TEXT UNIQUE NOT NULL` (app.py:58) and the 400
mapping (app.py:536-537).
